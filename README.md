# 麻煩整理所品牌入口

蔡鈞佑 Anson Tsai 的網域首頁：https://anson821012.github.io/。

此頁提供根網址的品牌名稱、WebSite 結構化資料、機器人 favicon 與分享圖。完整作品、服務及文章維持在 [anson-portfolio](https://anson821012.github.io/anson-portfolio/)；既有文章網址不搬移。

GitHub Pages 從 main 根目錄直接發布，`.nojekyll` 關閉 Jekyll 處理。不要覆蓋其他專案的 Pages 路徑。

## 維護

- `index.html`：根首頁、canonical、Open Graph / Twitter 分享資訊，以及 WebSite / Person 身分。
- `favicon-robot-96.png`、`apple-touch-icon.png`：與 anson-portfolio 相同的機器人圖示。
- `assets/share-robot-20260917.jpg`：1200 × 630 原創機器人分享封面。
- `robots.txt`：允許公開內容抓取，宣告根 Sitemap。
- `sitemap.xml`：索引根首頁網站地圖及持續更新的 portfolio 網站地圖。
- 原創圖像由 Codex 內建 imagegen 製作；最終提示詞記錄於 anson-portfolio 的 ART-DIRECTION.md。

Google 網站名稱與 favicon 由 Google 決定；設定更新後需等待重新抓取。社群分享預覽亦可能有快取，不能保證立即更新。

## 官方依據

- [Google 網站名稱](https://developers.google.com/search/docs/appearance/site-names)：名稱以網域或子網域首頁為單位。
- [Google favicon](https://developers.google.com/search/docs/appearance/favicon-in-search)：每個主機名稱一個圖示，由首頁宣告。
- [Open Graph](https://ogp.me/)：分享標題、說明、圖片及圖片屬性。
